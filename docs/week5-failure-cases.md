# 第五周错误与证据不足场景清单

以下是固定测试构造的异常场景，不是统计得到的真实模型错误率。

| 场景 | 风险 | 预期行为与证据 |
|---|---|---|
| 无测量或车辆上下文 | 把三串模拟值当作实车，套用未知阈值 | 规则返回 `insufficient_evidence`；Agent 提示补充电池类型、串数、测量条件 |
| 声明的串数不适用 | 把三串数据解释成其他电池结构 | 规则返回 `not_applicable` |
| 同一上下文有不同阈值 | 随机挑选有利结论 | 规则返回 `conflict`，要求核对 |
| 空检索 | 模型补造维修资料 | 立即返回证据不足，不继续第二轮模型调用 |
| 旧库无来源/版本，或资料未确认 | 给未知文本贴上权威来源 | 明确缺失字段，禁止作为已确认引用 |
| 模型未调工具就给结论 | 绕过证据链 | 注册知识工具的 Agent 返回固定补充证据提示 |
| 未引用、虚构引用、畸形引用 | 表面有来源，实际无法核对 | 丢弃模型结论，不进入成功记忆 |
| 多轮检索发生版本冲突 | 旧新依据混合 | 停止诊断并提示来源版本冲突 |
| 真实引用但语义不支持结论 | 引用校验无法识别所有事实错误 | 本周尚不能确定性阻断全部情况，需真实质量评测与人工核对 |
| 被测案例进入检索语料 | 提前把最终答案喂给模型 | 留一案例语料排除被测全文；回归输入不含最终判断、维修、复检 |

对应测试：`test_voltage_rules.py`、`test_knowledge_provenance.py`、`test_evidence_contract.py`、`test_week5_regression.py`。实际未通过的离线演示场景保存在 `reports/week5/evidence-demo.json` 的 `failures`；预期被拦截的场景通过，不等于系统执行失败。
